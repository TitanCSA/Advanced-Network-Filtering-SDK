# Scope and limits

This is a filtering component, not a complete VPN tunnel. Paths are not cryptographic executable identities. An application-specific rule cannot match absent app metadata. Policy is inactive until Start, and the demo fails open on expiry. Only the documented WFP layers and protocols are covered.

Event rings, process windows and queues are bounded. Overflow is reported and can make detection evidence incomplete. Never interpret missing events as proof that an operation did not occur. Callback code executes in the integrating process.
